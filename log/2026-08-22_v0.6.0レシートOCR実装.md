# 2026-08-22 spending-log v0.6.0 レシートOCR機能の実装

## 概要
`spec/receipt-ocr.md` の仕様に基づき、レシート画像から金額を自動読取する機能を実装した。

## 実装内容
`docs/index.html`

### HTML(`#entryModal` への追加)
- `.receipt-row`: 「📷 レシート読込(金額を自動入力)」ボタン + 非表示の
  `<input type="file" accept="image/*" capture="environment">`
- `.receipt-preview`: 選択したレシート画像のサムネイル + 読取ステータス表示
  (初期状態は非表示)

### CSS
- `.receipt-row` / `.receipt-btn` / `.receipt-btn:disabled` / `.receipt-preview` /
  `.receipt-preview img` / `.receipt-preview .receipt-status` を追加

### JS
- `TESSERACT_CDN_URL`: Tesseract.js(v5)をCDNから動的ロード(初回のレシート
  読込ボタン押下時のみ。通常起動時にはロードしない)
- `loadTesseract()`: 二重ロード防止のPromiseキャッシュ付きロード関数
- `extractAmountFromText(text)`: 「合計」等のキーワード優先、無ければ妥当な
  範囲(10〜1,000,000)の数値の最大値を採用する抽出ロジック(spec通り)
- `resetReceiptUI()`: モーダルを開き直すたびにレシート関連UIを初期状態に戻す
  (`openEntryModal()` 内で呼び出し)
- `receiptBtn` クリック→ファイル選択/カメラ起動トリガー
- `receiptFileInput` の `change` イベント: サムネイル表示→OCR実行→
  金額欄への自動反映→ステータス表示、失敗時は手入力へのフォールバックメッセージ
- サムネイル用の `object URL` はモーダルを閉じる/記録するタイミングで
  `URL.revokeObjectURL()` により破棄(レシート画像自体はどこにも永続化しない)

## 検証
ローカルの `py -3 -m http.server` 配信 + Claude Browserのモバイルビューポート上で:
1. 合成レシート画像(小計/消費税/合計を含む)をcanvasで生成し、File/DataTransfer
   経由で `#receiptFileInput` に注入して `change` イベントを発火
2. OCR実行後、ステータスに「金額を読み取りました: ¥1,296(内容を確認してください)」
   と表示され、`#amountInput` に `1296` が正しく反映されることを確認
3. サムネイル表示(`blob:` URL)、レシートボタンの読取中→通常表示への復帰を確認
4. 大項目選択後に記録ボタンが有効化されることを確認(既存フローとの結合確認)
5. モーダルを閉じて再度開いた際、レシートプレビュー・ファイル入力・金額欄が
   初期状態にリセットされることを確認
