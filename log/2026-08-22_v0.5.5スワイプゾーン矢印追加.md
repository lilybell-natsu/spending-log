# 2026-08-22 spending-log v0.5.5 スワイプゾーンへの矢印表示追加

## 概要
「スワイプゾーンがわかりやすいように画面遷移できる方向への矢印表示を記号としてつけて」
との指示。v0.5.4で追加した下部スワイプゾーンに、遷移方向を示す矢印記号を追加した。

## 変更内容
`docs/index.html`

### HTML
- `#swipeZone` の中身を、既存のつまみ(`.swipe-handle`)の両側に矢印を挟む構成に変更:
  `<span id="swipeArrowPrev">‹</span> <span class="swipe-handle"></span> <span id="swipeArrowNext">›</span>`
  - カレンダーの月切替ボタン(‹ ›)と同じ記号を使い、見た目の一貫性を持たせた

### CSS
- `.swipe-arrow`: 矢印のスタイル(サイズ16px、`--text-sub`色)
- `.swipe-arrow.disabled`: opacity 0.25 でグレーアウト表示

### JS
- `updateSwipeArrows()` を新設。`TAB_IDS` 内での現在タブのindexを見て、
  先頭(タブ1)なら `‹` を、末尾(タブ3)なら `›` を `disabled` クラス付与でグレーアウト
- `switchTab()` の中で毎回呼び出し、タブが変わるたびに矢印の状態を更新
- 初期表示時(ページ読み込み時)にも1回呼び出し、タブ1の初期状態(‹ が無効)を反映

## 検証
ローカルの `py -3 -m http.server` 配信 + Claude Browserのモバイルビューポート上で、
タブ1→2→3→1と切り替えながら矢印の `disabled` クラス状態をJSで確認:
- タブ1: ‹ 無効 / › 有効
- タブ2: ‹ 有効 / › 有効
- タブ3: ‹ 有効 / › 無効
いずれも意図通り。
