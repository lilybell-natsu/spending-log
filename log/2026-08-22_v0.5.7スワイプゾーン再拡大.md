# 2026-08-22 spending-log v0.5.7 スワイプゾーンの再調整(全画面使用時の干渉対策)

## 概要
v0.5.6でスワイプゾーンを画面最下端から10px浮かせ、高さも56px→40pxに縮小したが、
「アプリを全画面で使用するとまだ干渉する」との報告。
「縦方向の幅を増やす」「スワイプゾーン自体を広げる」の指示を受け、余白・サイズを
さらに拡大した。

## 修正内容
`docs/index.html`

### CSS
- `.swipe-zone`
  - `bottom:calc(10px + env(safe-area-inset-bottom))` →
    `bottom:calc(24px + env(safe-area-inset-bottom))` に拡大
    (画面最下端からの浮かせ距離を10px→24pxに)
  - `height:40px` → `height:56px` に拡大(ゾーン自体を広げる)
- `body` の `padding-bottom`: `calc(66px + ...)` → `calc(92px + ...)` に再調整
  (ゾーンの浮かせ距離24px + 高さ56px + 上側の余白分)

### JS
変更なし

## 検証
ローカルの `py -3 -m http.server` 配信 + Claude Browserのモバイルビューポート上で:
- `#swipeZone` のバウンディングボックスを確認: 画面最下端から24pxの隙間、高さ56pxを確認
- タブ3の履歴欄など本文コンテンツとゾーンが重ならないことを確認
- ゾーン内でのスワイプでタブが正しく切り替わることを再確認(回帰なし)

## コミット・push
ローカルコミット作成予定。push はユーザー自身の環境から実行してもらう運用を継続。

## 申し送り
実機のスタンドアロン(ホーム画面追加)表示でも引き続き干渉するようであれば、
浮かせる距離をさらに増やす、あるいはゾーンの位置を画面下部から離れた場所
(例: タブバー付近の画面上部)に変更することも検討の余地あり。
