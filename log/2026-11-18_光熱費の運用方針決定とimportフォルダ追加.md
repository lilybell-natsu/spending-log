# 2026-11-18 光熱費の運用方針決定と import フォルダ追加

## 何を行ったか
- 定期実行 `spending-log-utilities-monthly` の初回実行後、利用者の依頼で以下を対応
  - Googleドライブに保存した光熱費ファイルを、PC内の `import/` フォルダにも保存するようにした
  - sp-logへの取り込み方法を検討し、**スマホのsp-logを記録の正本とする運用(案B)** に決定
    - sp-logのデータは端末ごとのlocalStorageにしかないため、PCで取り込んでもスマホに反映されない
    - PCに集約する案(スマホのバックアップを全置き換えで復元→光熱費を取り込み直す)は、
      手順が多く記録を消す恐れがあるため不採用
    - PCは取得と保存(ドライブ・`import/`)のみ。取り込みは利用者がスマホの⚙→光熱費取込で月1回行う
