# spending-log# Spending-Log

スマホ利用を想定した、カレンダーベースの簡易家計簿PWA。

- タブ1: カレンダー(記録の追加・編集・削除)
- タブ2: 週間・月間の円グラフ
- タブ3: 直近3ヶ月の月間棒グラフ + 履歴

## 公開URL
GitHub Pages(`docs/` フォルダを公開ソースに設定)経由で公開。
`https://<ユーザー名>.github.io/<リポジトリ名>/`

## データ保存
現状はブラウザのlocalStorageにのみ保存(端末・ブラウザをまたいだ同期はなし)。
将来的にバックエンド化し、複数端末・複数利用者間での共有機能を追加予定(フェーズ2)。

## バージョン管理
`CHANGELOG.md` に変更履歴を記録。バージョンは「メジャー.マイナー.軽微」の3点でナンバリング。
